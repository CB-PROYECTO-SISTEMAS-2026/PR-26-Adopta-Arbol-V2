# PR-26-Adopta-Arbol-V2

Aplicacion fullstack para adopcion y seguimiento de arboles.

## Inicio rapido

### 1) Instalar dependencias

```bash
npm run install-all
```

### 2) Levantar backend (raiz)

```bash
npm run dev
```

### 3) Levantar frontend (en otra terminal)

```bash
cd client
npm run dev
```
